# Rock-Paper-Scissors AI Game

An intelligent Rock-Paper-Scissors game where the AI learns your playing patterns to beat you!

## Features
- Pattern recognition AI
- Clean GUI interface
- Real-time statistics
- Learning algorithm that adapts to player behavior

## How to Run
```bash
python gui.py
```

## How It Works
The AI tracks your move history and identifies patterns. After 5+ games, it predicts your next move based on:
1. Recent move sequences
2. Historical patterns
3. Move frequency

## Technologies Used
- Python 3.x
- Tkinter (GUI)
- Pattern Recognition Algorithm
